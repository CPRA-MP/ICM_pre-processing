Various tools (Excel, Python, R) used to analyze CRMS observations to:

1 - calculate a shallow soil factor parameterizing near-surface elevation change in the soil column that is assumed to be separate from geologic subsidence

2 - calculate the inundation threshold depths (as a function of salinity) which will define the upper bound of inundation tolerance for vegetated wetland survival as land in ICM-Morph (aka, the "blue line curve")
